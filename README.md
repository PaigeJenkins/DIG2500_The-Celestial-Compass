# The Celestial Compass

## Project Option
Website

## Project Description
The Celestial Compass is a website designed for future space tourists. Users can browse destinations throughout the Solar System, pin locations to create a personalized itinerary, explore verified resources from NASA and National Geographic, view a (purposely annoying) travel supplies pop-up ad, and check a list of important documents and items to bring before their journey.

## Theme Interpretation
The project responds to the Space theme by immersing users in a futuristic travel experience. A galaxy hero image, destination cards featuring planets and moons, and a space travel planner interface encourage users to imagine planning a vacation through the Solar System.

## Intended User or Player
Future space tourists.

## User or Player Goal
Plan a space vacation, learn more about destinations, and remember important travel documents and supplies before departing.

## Main Features
- Hero image with greeting and call to action
- Horizontally scrolling destination cards
- Pin destinations to create an itinerary
- Learn More section with NASA and National Geographic resources
- Travel checklist with important documents and supplies
- Pop-up advertisement for travel supplies

## JavaScript Features
- Pinning destinations updates the itinerary automatically.
- Left and right arrow buttons scroll through the destination cards.
- A pop-up advertisement appears when the page loads and can be dismissed by the user.

## Responsive Design
The website adapts to different screen sizes using a media query. Destination cards become narrower on smaller screens, and side-by-side sections stack vertically to remain readable and easy to navigate.

## User Testing
One classmate tested the website using Google Chrome on a laptop. They found the purpose of the website clear, navigation easy to use, and the itinerary feature intuitive. Their main suggestion was to finish the destination information and images to make the experience feel more complete.

## Revisions

- Added the Learn More section with NASA and National Geographic resources.
- Added the travel checklist section.
- Improved the itinerary feature by allowing users to pin destinations.
